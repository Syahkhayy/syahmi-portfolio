# Syahmi Portfolio Page — Project Brief

## 🧰 Tech Stack
- HTML (structure)
- Tailwind CSS (styling via CDN)
- Minimal JavaScript (optional, for small interactions)

---

## ✨ Features (Max 3)
1. **Project Showcase (with placeholders)**
   - Display 2–3 project cards
   - Include "In Progress" / "Coming Soon" where needed

2. **About Me Section (Personal)**
   - Short, human introduction
   - Light personality (simple, not corporate)

3. **Contact (Call-To-Action)**
   - GitHub, LinkedIn, Email
   - Icon-based links

---

## 🧱 Sections (Single Page Layout)
1. **Hero Section**
   - Avatar (circular)
   - Name: Syahmi
   - Tagline: "Malaysian Software Engineer | Building and improving every day"
   - CTA Buttons: View Projects, Get In Touch

2. **About Section**
   - 3–5 lines introduction
   - Personal tone with a bit of humor

3. **Projects Section**
   - 3 cards in a row (desktop)
   - Includes placeholder projects
   - Shows title, description, status tag (In Progress / Completed) and tech stack

4. **Contact Section**
   - Short message
   - Icons for GitHub, LinkedIn, Email

5. **Footer (Optional)**
   - Simple copyright line

---

## 🛠️ Build Steps

### Step 1 — Setup
- Create `index.html`
- Add Tailwind CDN

### Step 2 — Build Hero Section
- Add avatar, name, tagline, buttons
- Apply gradient background

### Step 3 — Add Remaining Sections
- About
- Projects
- Contact

### Step 4 — Fill Real Content
- Write your actual intro
- Add project placeholders intentionally

### Step 5 — Style the Page
- Center layout
- Add spacing, font sizes, colors
- Style buttons and cards

### Step 6 — Add Interactions
- Button hover effects
- Card hover (slight scale/lift)
- Icon hover effects

### Step 7 — Make Responsive
- Stack sections for mobile
- Ensure cards become 1 column

### Step 8 — Deploy
- Use GitHub Pages or similar hosting

---

## 🎯 Goal
Build a clean, simple, and complete personal portfolio in a few hours.
Focus on finishing, not perfection.
